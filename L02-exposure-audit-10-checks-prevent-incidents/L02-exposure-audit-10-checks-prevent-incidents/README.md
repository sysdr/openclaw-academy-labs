# Lesson 02 - Exposure audit: the 10 checks that prevent most incidents

**Goal:** a read-only audit script that checks the running Lesson 01 sandbox from three vantage points (your host, Docker, and OpenClaw itself) and fixes what it finds.

**Proof:** `make verify` prints `10/10 PASS`, exits 0, and writes `reports/verify-<time>.txt`.

Verified on OpenClaw **2026.10.5** (`latest` on npm, 18 Oct 2026), Docker Engine 29.9, Compose v2, Python 3.13. See `VERIFICATION.md` for every command and key with its source.

- Code: https://github.com/sysdr/openclaw-academy-labs-p/tree/main/L02-exposure-audit-10-checks-prevent-incidents
- Article: OpenClaw Academy, Lesson 02 (https://openclawacademy.substack.com)

## Quickstart

```bash
make bootstrap            # prerequisites; recreates Lesson 01's sandbox if you skipped it
make build && make run    # pinned image, gateway healthy on 127.0.0.1:18789
make verify               # the "before" audit: 8/10 on a Lesson 01 baseline
make setup                # apply config/l02-hardening.patch.json5, tighten file modes
make verify               # 10/10 PASS
```

## Coming from Lesson 01

Stop the Lesson 01 gateway first (both publish port 18789): `docker compose -p openclaw-l01 down`. To audit your Lesson 01 state rather than a fresh baseline, uncomment `STATE_DIR` in `.env`; bootstrap keeps any state it finds.

## The 10 checks

1. Gateway port published on loopback only (`docker port`)
2. Gateway requires a token or password (`gateway.auth.mode` + audit findings)
3. OpenClaw's own audit: 0 critical findings (`openclaw security audit --json`)
4. OpenClaw's own audit: 0 warnings, and every suppression has a reason
5. No `dangerously*` flags, active or suppressed
6. Exec policy is not `security=full` and falls back to `deny` (`openclaw approvals get --json`)
7. `.env` 600 and git-ignored, `state/openclaw` 700, `openclaw.json` 600
8. Container runs non-root with all capabilities dropped and `no-new-privileges`
9. Container is not privileged, joins no host namespace, mounts no runtime socket
10. Running version equals the pin and is past 2026.1.29 (CVE-2026-25253)

## Files

- `Makefile`: one target per script (`audit` runs the audit without writing a report).
- `scripts/audit.sh`: collects evidence, runs the 10 checks, prints one PASS/FAIL line each. Read-only.
- `scripts/verify.sh`: the proof. Runs the audit, requires 10/10, writes `reports/verify-<time>.txt`.
- `scripts/bootstrap.sh`: prerequisites; recreates Lesson 01's end state (token auth, exec deny) without a model key.
- `scripts/setup.sh`: applies the hardening patch, chmods `.env`/state/config, restarts the gateway.
- `scripts/build.sh`: pinned image present, compose valid, prints the version.
- `scripts/run.sh`: starts the gateway and waits for Docker's `healthy`.
- `scripts/demo.sh`: 60 seconds: flip mDNS to `full`, watch check 3 fail, restore, 10/10 again.
- `scripts/test.sh`: unit tests, mock end-to-end, shellcheck, integration.
- `scripts/clean.sh`: stops the gateway; deletes `state/`, `reports/`, `.env` only if you type `yes`.
- `scripts/lib.sh`: shared helpers (compose wrapper, `oc` CLI-in-container, portable file modes).
- `src/l02_audit.py`: the 10 checks as pure functions over an evidence folder (standard library only).
- `docker/compose.yaml`: Lesson 01's sandbox, pin bumped to 2026.10.5.
- `config/l02-hardening.patch.json5`: allowed origins, auth rate limit, mDNS off. Keys in `config/README.md`.
- `config/exec-approvals.json`: Lesson 01's exec policy (deny), used by bootstrap.
- `fixtures/cases.json`: a passing and a failing evidence set (OpenClaw parts are real 2026.10.5 output).
- `expected/verify-pass.txt`, `expected/verify-fail.txt`: the PASS/FAIL column for each state.
- `tests/test_audit.py`: 15 unit tests, no Docker or OpenClaw needed.
- `tests/mock/docker`: a fake `docker` CLI that serves the fixtures.
- `tests/e2e_mock.sh`: runs the real `verify.sh` against the mock, passing and failing.
- `tests/integration.sh`: real image in a throwaway copy on port 18799: 8/10, setup, 10/10, drift 9/10, 10/10.
- `solution/drift.sh`: the assignment: baseline the audit, then fail on anything new.
- `.env.example`: placeholders only. `.env`, `state/` and `reports/` stay on your machine.

## Credentials and their scope

- `OPENCLAW_GATEWAY_TOKEN`: generated by `make bootstrap` (32 random bytes), stored only in `.env` (mode 600). It authorizes operators of this one gateway. The audit never prints it.
- No model or provider key is needed for this lesson: the audit reads configuration and never sends a prompt.

## Safety notes

- The audit is read-only. Only `make setup` changes config, and only the three keys in the patch file.
- `make demo` sets `discovery.mdns.mode=full` for about 30 seconds and restores `off` on exit, including Ctrl-C.
- The gateway stays published on `127.0.0.1` only; exec stays at `deny`.
